# Sticker pairs

Open Today → Little adventures → Sticker pairs.

An optional twelve-card matching game uses the six existing sticker designs. All designs are available regardless of collection progress. Cards reveal on tap or keyboard activation; matching pairs stay revealed, with a text label as well as a color change. Unmatched cards stay visible until the player chooses to turn them back. Shuffle & restart creates a fresh board; finishing offers Play again.

The board is session-only and resets when leaving the game view. No collection, journal, account or API writes. Momo commentary follows mascot visibility. Card artwork has a finite reveal animation, disabled by calm, still and reduced-motion preferences. Controls retain their position and keyboard focus.
